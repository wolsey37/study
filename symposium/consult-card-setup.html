작업 폴더 두기

약 1분

사이언스와 클로드가 같은 폴더를 쓰도록, 킷의 workspace 폴더를 홈 폴더에 둡니다.

  1. consult-card-kit.zip을 받아 두 번 클릭합니다.

    다운로드 폴더에 workspace 폴더가 생기고, 그 안에 pharmacy 폴더가 있습니다

  2. Finder에서 홈 폴더를 열고(⌘+⇧+H), workspace 폴더를 그 안으로 끌어다 놓습니다.

    최종 위치가 아래와 같으면 됩니다

    ~/workspace/pharmacy

    홈에 workspace 폴더가 이미 있다면, 통째로 옮기지 말고 안의 pharmacy 폴더만 기존 workspace 폴더로 옮기세요. "대치할까요?"라는 창이 뜨면 대치를 누르지 마세요. 기존 폴더의 파일이 지워집니다.

    설정한 뒤에는 이 폴더를 옮기지 마세요. 옮기면 설정을 다시 해야 합니다.

클로드 사이언스 프로젝트Claude Science

약 2분

논문을 찾아 pharmacy 폴더에 보고서로 저장하는 규칙을 넣어 둡니다.

  1. 클로드 사이언스 첫 화면 오른쪽 위 + New project를 누릅니다.

  2. Name 칸에 이름을 넣습니다.

    상담카드

  3. Agent Context 칸에 규칙을 붙여 넣습니다.

    Description 칸은 비워 둬도 됩니다
    규칙 내용 보기
    # 논문 근거 보고서 규칙

## 1. 범위
- 제품 이름을 받으면 주성분을 먼저 확인하고, 주성분 기준으로 함량·연령을 가리지 않고 찾는다.
- 효능과 주의사항, 임상시험을 포함한다.

## 2. 논문 인용
- PubMed에서 PMID·DOI가 실제로 확인되는 논문만 쓴다.
- 문장마다 PMID와 대상 연령·용량·투여횟수를 붙인다.
- 찾지 못한 근거는 지어내지 말고 "없음"이라고 쓴다.

## 3. 저장
- 경로: ~/workspace/pharmacy/00_근거함/<접두어>_논문근거보고서.md
- 접두어: 키워드의 공백 · "·" · ","를 "_"로 바꾼 것
  예) 지르텍정 · 클라리틴정 · 알레그라정120mg → 지르텍정_클라리틴정_알레그라정120mg

## 4. 형식
- 맨 위에 요약 표: 제품 | 주성분 | 논문 수 | 소아 근거
- 절마다 번호 소제목, 절 사이에 구분선(---)
- 문장 끝 PMID와 연령·용량은 굵게
- 소아·임부 등 주의사항 문장 앞에 ⚠, 찾지 못한 근거는 ❌ 없음
- 핵심 결론은 인용 블록(>)으로

  4. 오른쪽 아래 Create를 누릅니다.

클로드 프로젝트Claude

약 3분

pharmacy 폴더를 연결하고, 폴더 안의 작업 지침을 먼저 읽도록 알려 둡니다.

  1. 클로드 데스크톱 앱 왼쪽 프로젝트 → 오른쪽 위 새 프로젝트를 누릅니다.

  2. 무엇을 작업 중이신가요? 칸에 이름을 넣습니다.

    약국 검증 자료

  3. 폴더 사용을 누르고 workspace 안의 pharmacy 폴더를 고른 뒤 프로젝트 생성을 누릅니다.

    폴더 권한을 묻는 창이 뜨면 허용

    workspace가 아니라 그 안의 pharmacy를 골라야 합니다.

  4. 프로젝트 화면 오른쪽 지침 옆 +(또는 연필)를 누르고, 지침을 붙여 넣은 뒤 지침 저장을 누릅니다.

    지침 내용 보기
    이 프로젝트는 약국에서 쓸 자료를 국내 허가사항 기준으로 검증해서 만드는 곳이다. 작업 폴더는 이 프로젝트에 연결된 pharmacy(~/workspace/pharmacy)다.
"지침_<이름>, <키워드>" 형식의 요청을 받으면 작업 폴더의 지침_<이름>.md 파일을 먼저 읽고 그 지침을 그대로 따라라.
예: "지침_상담카드, 지르텍정 · 클라리틴정 · 알레그라정120mg" → 지침_상담카드.md 를 읽고 실행
지침을 읽기 전에는 작업을 시작하지 마라.
